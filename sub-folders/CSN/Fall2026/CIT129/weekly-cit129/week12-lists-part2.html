Using .index() paired with the in keyword to prevent runtime errors.

Safe Search Pattern
if target in names:
    idx = names.index(target)
    # Safe to access parallel data
    print(ages[idx])
else:
    print("Value not found!")

Checking in first prevents Python from throwing a ValueError when searching for non-existent items like "Howard".

Parallel Swap Algorithm
for i in range(len(ages)):
    for j in range(len(ages) - 1):
        if ages[j] < ages[j + 1]:
            # Swap Main List
            ages[j], ages[j+1] = ages[j+1], ages[j]
            # Swap Secondary Lists
            names[j], names[j+1] = names[j+1], names[j]
            heights[j], heights[j+1] = heights[j+1], heights[j]
