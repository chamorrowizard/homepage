🚩 1. Flag-Controlled Loops

A flag-controlled loop is utilized when multiple distinct exit conditions must be managed simultaneously (such as combining a counter limit with a correct sentinel trigger).

Basic Loop Structure

# Define a flag first. It must start as True.
my_flag = True

# Start a loop using the flag.
while my_flag:
    # Perform operations...
    # When ready to exit, toggle the flag to False.
    my_flag = False

Applied Example: Number Guessing Game

secret = 9
guesses_left = 5
game_is_on = True

while game_is_on:
    guess = int(input("Guess a number between 1 and 10: "))
    guesses_left -= 1

    if guess == secret:
        print("You guessed it! Yay!")
        game_is_on = False  # Exit condition 1: Success
    elif guesses_left == 0:
        print("You ran out of guesses.")
        game_is_on = False  # Exit condition 2: Limit reached

Trade-off Note: While highly flexible, flag loops can be less readable at a glance because exit logic is evaluated inside the block rather than explicitly in the loop header.

🖨️ 2. Advanced Print Function Modifiers

By default, Python's print() function automatically inserts a newline character (\n) and separates multiple items with a space. We can customize this behavior using keyword arguments.

Controlling Line Endings with end=""

To print list items horizontally across a single line instead of stacking them vertically:

names = ['Alex', 'Muhammad', 'Yasmin', 'Bianca', 'Naomi']

# Using a space string to prevent items from merging together
for i in range(len(names)):
    print(names[i], end=" ")

# Output: Alex Muhammad Yasmin Bianca Naomi

Controlling Separators with sep=""

To remove unwanted default spaces inserted between concatenated arguments:

# Default behavior places a space before the value
print("Your total price is $", 10.99)  # Outputs: Your total price is $ 10.99

# Using sep="" removes the separator space entirely
print("Your total price is $", 10.99, sep="")  # Outputs: Your total price is $10.99
🛠️ Engineering Lesson: Precision

Small details matter. Adjusting parameters like separators and line endings demonstrates the software engineering mindset: taking exact control over the presentation layer to ensure a polished user experience.
