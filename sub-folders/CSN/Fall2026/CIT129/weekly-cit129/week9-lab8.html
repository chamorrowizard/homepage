🔢 1. Scoring State & Numeric Casting (Q1)

We begin by initializing our accumulator variable to track correct answers, then use type casting for numeric input.

score = 0

q1_answer = int(input("How many states are in Canada?: "))
if q1_answer == 13:
	score += 1
	print("Correct!")
  • Accumulator (`score = 0`): Acts as a secure container that increments whenever a condition is met.
  • Type Casting (`int()`): Converts raw user string input into an integer so it can be compared mathematically using `==`.

🔤 2. String Sanitization with .lower() (Q2 & Q3)

User input can vary wildly in capitalization (e.g., "San Salvador", "san salvador", "SAN SALVADOR"). We standardize input to ensure fair evaluation.

q2_answer = input("What is the capital of El Salvador?: ").lower()
if q2_answer == "san salvador":
	score += 1
	print("Correct!")
  • Method Chaining (`.lower()`): Instantly converts all alphabetic characters in the string to lowercase right as input is captured, preventing minor typing discrepancies from failing a correct answer.

🎯 3. Range Checking (Q4)

When a question has multiple valid historical answers or a span of correct years, we evaluate ranges efficiently.

q4_answer = int(input("What is ONE of the years that Franklin D. Roosevelt was in office?: "))
if 1933 <= q4_answer <= 1945:
	score += 1
	print("Correct")
  • Chained Inequality: Evaluates whether the user's entered year falls inclusively between Roosevelt's inauguration (1933) and conclusion of office (1945).
🛠️ Engineering Lesson: Robust Design

Anticipating user behavior—such as typing variations or multiple correct answers—demonstrates mature software design. Robust programs account for flexibility while maintaining strict boundaries.
