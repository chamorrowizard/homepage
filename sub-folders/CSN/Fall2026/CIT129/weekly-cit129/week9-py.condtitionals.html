Control Flow if / elif / else

The Conditional Chain

Conditional statements allow your program to make decisions. They evaluate boolean expressions to determine which block of code runs.

if True: # Evaluated first
    print("Runs when condition is True")
elif True: # Evaluated if previous was False
    print("Runs if first is False and this is True")
else: # Fallback block
    print("Runs when none above are True")
Logic Operators Comparisons & Case Sensitivity

Evaluating Expressions

Comparisons always resolve to either True or False. Python is strictly case-sensitive when comparing strings.

x == 12 Equal (True)
x != 20 Not Equal (True)
x >= 12 Greater/Equal (True)
x < 8 Less Than (False)
Pro Tip: Use .lower() to normalize input data:
if name.lower() == "john".lower(): # Matches regardless of case
Boolean Logic and / or / not

Compound Conditions

Combine multiple evaluations using boolean operators to handle complex criteria.

AND

Both sides must be True.

True and True → True

OR

Either side can be True.

False or True → True

NOT

Inverts the boolean state.

not True → False
