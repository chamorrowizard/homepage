Counter Loops for i in range(...)

The Range Function

Counter loops handle repetitive tasks using 3 core elements: counter, upper bound, and increment. Python's range() function handles this dynamically.

1 Digit: stop

Starts at 0, goes up to stop - 1.

range(5) → [0..4]

2 Digits: start, stop

Custom start, stops before stop.

range(2, 6) → [2..5]

3 Digits: start, stop, step

Custom increment steps.

range(0, 5, 2) → [0, 2, 4]

# Modern Python Way
for i in range(num_of_items):
    print(i)
Data Integrity Validation Loops

Input Validation

Validation loops force users to re-enter data until it meets strict criteria (e.g., ensuring a price falls between 1 and 100).

# Method 2 Prime-and-Read approach
price = -1
while price < 1 or price > 100:
    price = float(input("Please enter a price between 1 and 100: "))
Accumulation Summation & F-Strings

Summation & Formatting

Summation requires an accumulator initialized outside the loop. Averaging divides the final total by the total quantity. Use f-strings with :.2f to format floating-point numbers to two decimal places.

total_calories = 0 # <- Accumulator
for i in range(num_of_candies):
    total_calories += calories
average = total_calories / num_of_candies
print(f"Average: {average:.2f}") # 2 decimal places
Flow Control Rule Sentinels vs. Break

Sentinel Loops & The "No-Break" Rule

A sentinel value signals the loop to stop (e.g., entering 0 to exit).

CRITICAL CLASS RULE: Do NOT use break or continue statements in CIT 129 loops. They make execution flow less readable and violate core structured programming principles!
