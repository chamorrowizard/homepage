Input Validation, Accumulator Loops, and Decision Structures

📜 Full Source Code Reference

Here is the complete script analyzed across this study portal:

num_of_temps = int(input("Enter the number of temperature readings: "))
while not ( 1 <= num_of_temps <= 50):
	print("Enter a number between 1 and 50 inclusive.")
	num_of_temps = int(input("Invalid.Enter the number of temperature readings: "))

total_f = 0
total_c = 0

for i in range(num_of_temps):
	temp_c = float(input(f"Enter temp #{i + 1} in Celsius (-100 to 200): "))
	while not (-100 <= temp_c <= 200):
		temp_c = float(input(f"Invalid. Enter temp #{i + 1} in Celsius (-100 to 200): "))
	
	total_c += temp_c
	temp_f = 9/5 * temp_c + 32
	total_f += temp_f
	
	print(f"The temp in Fahrenheit is {temp_f:.2f}")
	
	if temp_f < 40:
		print("cold")
	elif 40 <= temp_f <= 80:
		print("okay")
	else:
		print("Hot")

average_f = total_f / num_of_temps
average_c = total_c / num_of_temps

print(f"Average temperature in Fahrenheit is {average_f:.2f}")		
print(f"Average temperature in Celsius is {average_c:.2f}")

🛡️ 1. Initial Range Validation Loop

Before any processing happens, we ensure the user inputs a safe and logical quantity of readings using a while not (...) sentinel loop.

num_of_temps = int(input("Enter the number of temperature readings: "))
while not ( 1 <= num_of_temps <= 50):
	print("Enter a number between 1 and 50 inclusive.")
	num_of_temps = int(input("Invalid.Enter the number of temperature readings: "))
  • Chain Comparison: Python allows clean range evaluation like `1 <= num_of_temps <= 50`.
  • The Guard: `not (...)` means the loop keeps executing as long as the user's input is outside the accepted boundaries.
