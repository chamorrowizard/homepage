Mastering flexible control structures, unknown iteration counts, and independent tracking state patterns in pseudocode.

Sentinel-controlled Loop Pattern 1

Used when execution count is unknown beforehand

Sentinel-controlled loops execute until a specific predetermined value (the sentinel) is explicitly provided by the user to trigger loop exit.

Trigger Keywords: "Keep going until the user enters ___", "Stop when ___ is entered"

Core 3-Part Architecture:

  • Initial Prompt: Ask for the first piece of data outside the loop.
  • Condition Check: Loop continuously while data != sentinel.
  • Subsequent Prompt: Request data update inside the loop using the exact same variable.
PSEUDOCODE EXAMPLE Sentinel Pattern
PRINT "Please enter your exam score. Enter -1 to exit." INPUT score WHILE score != -1: # Processing logic goes here PRINT "Please enter another exam score. Enter -1 to exit." INPUT score

Counters Beyond Counter-Loops Concept

Tracking state independently of loop execution logic

A counter doesn't always have to control a loop. It can exist solely to tally specific occurrences or events inside a body of looping code.

Trigger Keywords: "Count how many...", "Track how many..."
SOLO COUNTER PATTERN State Management
SET apple_count = 0 # Initialize before loop starts # Inside any loop structure... IF fruit == "apple": SET apple_count = apple_count + 1

Example 1: Solo Counter + Counter Loop

Managing two distinct counter variables

Scenario: Prompt user for total exam count. For each exam, ask for the score and count how many scores are under 70.

PSEUDOCODE IMPLEMENTATION
PRINT "How many exams do you have?" INPUT num_of_exams SET bad_score_count = 0 <-- Tally Counter SET count = 1 <-- Loop Control Counter WHILE count <= num_of_exams: PRINT "What is the score for that exam?" INPUT score IF score < 70: SET bad_score_count = bad_score_count + 1 SET count = count + 1

Example 2: Solo Counter + Sentinel Loop

Tallying items when execution count is unpredictable

Scenario: Ask for weight of items being purchased. Keep looping until a negative weight is given. Count total items processed.

PSEUDOCODE IMPLEMENTATION
PRINT "Enter weight of item. Enter negative to stop." INPUT weight SET item_count = 0 WHILE weight >= 0: SET item_count = item_count + 1 PRINT "Enter weight of another item. Enter negative to stop." INPUT weight
