2. Comparison Operators

Conditions are statements that evaluate to a Boolean value: True or False.

Operator Syntax Meaning Example Evaluates To
A > BIs A greater than B?7 > 21False
A >= BIs A greater than or equal to B?12 >= 12True
A < BIs A less than B?12 < 12False
A <= BIs A less than or equal to B?12 <= 15True
A == BIs A strictly equal to B?6 == 7False
A != BIs A not equal to B?6 != 7True

4. Comprehensive Example: Grade Evaluation

Checking numeric ranges requires using boundary logic via compound operators to avoid edge-case evaluation bugs.

PRINT "Please enter your score (0-100)" INPUT score IF score >= 90 AND score <= 100: PRINT "A" ELSE: IF score >= 80 AND score < 90: PRINT "B" ELSE: IF score >= 70 AND score < 80: PRINT "C" ELSE: IF score < 70: PRINT "D"
